Quick filters

The button row in the filter bar on Browse, Map, Review, Duplicates and Misses. Clicking a button there adds its rule to the current filter; clicking it again removes it. Buttons that share a group combine with OR — with both “Missing species” and “Missing location tag” on, the grid shows photos missing either tag, and the flag buttons work the same way. Buttons you add here are ungrouped, so they narrow whatever else is on (AND). A button whose value a page hides — “Rejected” on Misses — is hidden on that page instead of returning nothing.

Location metadata in XMP

Assigning a place in Vireo queues a sidecar write for that photo. What the write does is decided by two settings in the Metadata category below — write_assigned_location_to_xmp writes GPS coordinates, write_location_keywords_to_xmp writes the place and its parents as XMP keywords. Photos you located before turning a setting on have nothing queued, so they need a one-off backfill.

External Editors

Applications used by "Open in Editor" context-menu and app-menu actions. Add as many as you like (e.g. Lightroom, Affinity, Photoshop); context menus show each configured editor, while the app menu uses the first. With none configured, photos open in the OS default app.

Remote targets (NAS / SSH)

Destinations for moving folders to a NAS over SSH — far more reliable than an SMB mount over a slow/remote link, with resume and integrity verification. The Remote path is the NAS-side filesystem path rsync writes to (e.g. /volume1/Photography); the Local mount path is where you can read those same files afterward (e.g. /Volumes/Photography) — moved photos are repointed there so they stay in your library. Remote moves need GNU rsync (set its path under “GNU rsync path” in the Paths settings if auto-detect fails). Local archive root is the local folder that mirrors the remote path. Imports under this folder can chain an automatic move to this target after processing. It must be an absolute path outside the local mount path — other values are cleared on save.
