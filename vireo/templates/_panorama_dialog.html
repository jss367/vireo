Create Panorama

Choose 2–12 views taken from the same position with about 30–50% overlap. Current edits are included. Originals stay unchanged.

Saved as the first photo’s name plus “_panorama”. Existing files are preserved by adding a number. Rescan the output folder to add the result to Browse.

The panorama can be wider than this limit. Output is 8-bit color; alignment can leave black borders that you can crop after importing.
